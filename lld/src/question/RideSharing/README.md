# Ride - Sharing System Like UBER

---


## Functional Requirement 

### 1. User

- Book Ride
- Cancel Ride
- View Fare Estimate
- Track Ride
- Make Payment
- Rate Driver (Optional)

### 2. Driver

- Go Online/Offline
- Accept Ride
- Cancel Ride
- Start Ride
- End Ride
- Update Location
- Rate Rider

### 3. Platform (System)

- Match Rider With Nearest Driver
- Maintain Driver Availability
- Calculate Fare
- Provide Route
- Handle Payment
- Define Ride Types (Bike, Sedan, XL, etc.)
